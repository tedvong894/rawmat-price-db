📲 安装到本地（Mac）

你的浏览器（Safari）需要通过系统菜单安装：

  1. 打开本页面后，点击顶部菜单栏的 「文件」
  2. 选择 「添加到 Dock」（macOS Sonoma 14+）
  3. 稍候即可在 启动台 / Dock 看到「原料价格」独立应用

旧版 macOS 可用 Chrome 打开本页，点右下角「安装到本地」即可。

检测到你用的是 Chrome / Edge，直接点击下方按钮即可安装为桌面应用：

  1. 点击 「安装应用」，确认后自动生成桌面应用
  2. 之后可在 启动台 / 应用程序 找到「原料价格」

不同浏览器安装方式略有差异：

  • Chrome / Edge：地址栏右侧点「安装」图标，或点本页「安装到本地」按钮
  • Safari (Mac)：菜单「文件」→「添加到 Dock」
  • 手机：浏览器「分享」→「添加到主屏幕」
